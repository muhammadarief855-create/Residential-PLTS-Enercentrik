Cara menyiapkan (sekali saja, oleh satu orang)
  1. Buka console.firebase.google.com, login dengan akun Google, lalu Add project. Nama bebas, Analytics boleh dimatikan.
  2. Di menu Build pilih Realtime Database, klik Create Database, pilih lokasi Singapore, lalu mulai dalam locked mode.
  3. Buka tab Rules, hapus isinya, tempel teks di bawah, lalu klik Publish.
  4. Buka tab Data. Salin alamat di bagian atas (berawalan https://, berakhiran firebasedatabase.app atau firebaseio.com), tempel di kolom di atas, lalu tekan Jadikan bersama.
  5. Tekan Salin link tim dan kirim ke teknisi. Siapa pun yang punya link bisa melihat dan mengubah ceklis ini.
{
  "rules": {
    "checklists": {
      "$room": { ".read": true, ".write": true }
    }
  }
}
Salin link di bawah lalu kirim lewat WhatsApp. Siapa pun yang membukanya bisa memuat hasil ini.

Ketuk kotak tahap untuk mengganti status: kosong, lalu ✓ (ada), lalu ✗ (tidak ada). Setiap ketukan tersimpan otomatis di HP atau browser ini dan terbuka lagi saat link dibuka. Tekan Simpan di bagian bawah untuk memastikan dan melihat konfirmasinya.
